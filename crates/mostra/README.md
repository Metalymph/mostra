# Mostra

Mostra is an open-source, local-first engine for personal data exposure analysis.

The project is designed as an application-agnostic Rust core with future
semantically consistent C and WebAssembly interfaces.

## Status

Version **0.0.1** is an initial namespace and architecture bootstrap.

The public API is deliberately minimal while the exposure model, evidence model,
matching semantics and remediation workflow are designed.

## Principles

- local-first
- deterministic
- privacy-preserving
- application-agnostic
- Rust as canonical implementation
- future C ABI
- future WebAssembly ABI
- no mandatory remote service
